## 📚 核心知识体系

### 八星体系总览

| 类别 | 星位 | 五行 | 核心象意 |
|------|------|------|----------|
| 🌟 吉星 | 生气 | 阳木 | 朋友、贵人、正能量、随缘 |
| 🌟 吉星 | 延年 | 阳金 | 事业、责任、地盘、掌控 |
| 🌟 吉星 | 天医 | 土 | 财、正桃花、婚姻、善良 |
| 🌟 吉星 | 伏位 | — | 延续、聚集、慢半拍 |
| ⚡ 凶星 | 绝命 | 阴金 | 行动力、投资、拼搏、冲动 |
| ⚡ 凶星 | 五鬼 | 火 | 脑力、变通、机会、不稳定 |
| ⚡ 凶星 | 祸害 | 土 | 口才、表达、脾气、口舌 |
| ⚡ 凶星 | 六煞 | 水 | 服务、公关、亲和、桃花 |

> 💡 选号不是一味追吉，而是**吉凶相配、本性与能力平衡**。

### 号码分析六步法

```
① 看结尾    → 权重约70%，是最终结果
② 看分值    → 找最突出的能量场
③ 看0和5   → 0=问题点，5=升能量桥梁
④ 看搭配    → 前因后果，顺位作用，隔位不作用
⑤ 看五行    → 磁场单一时辅助参考
⑥ 看命卦    → 结尾必须符合东西四命
```

### 东西四命速算

```
年份各位相加 → 加到个位
男：11 - 个位数   女：个位数 + 4
（得5时：男按2，女按8）

1349组 → 东四命    2687组 → 西四命
```
