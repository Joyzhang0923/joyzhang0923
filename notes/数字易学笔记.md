## 二、底层逻辑：八宅风水与八星来源

- 数字不是孤立数字，而是九宫格与八卦配卦后的能量符号
- 八宅风水传统讲「门、主、灶」，数字课程借用其配卦思想
- **四吉星**：生气、延年、天医、伏位 → 偏本性
- **四凶星**：绝命、五鬼、六煞、祸害 → 偏能力
- 匹配号码主张「**吉凶相配、能量平衡、符合命卦**」
- 老师金句：「号码只能助你一时，助不了你一世」

## 四、八星基础物象详细笔记

### 🌱 生气星（阳木，主仁）
- **关键词**：积极阳光、正能量、心态平和、随缘、人缘与朋友运
- **适用**：朋友、贵人、群众基础；退休、养老、轻松心态人群
- **风险**：过强或反噬时，与肠胃、消化系统象意相关

### ⚔️ 延年星（阳金，主义）
- **关键词**：责任、担当、地盘感、事业心、条理性、掌控欲、话语权
- **适用**：男人号码中通常需要延年
- **小延年**（26/62、34/43）：偏内敛、踏实、旺家
- **大延年**（78/87、19/91）：偏掌控、事业、压力；**女性慎用**
- **风险**：压力、心肺、肩颈；大延年女性易强势或单身倾向

### 💰 天医星（土，主信）
- **关键词**：心地善良、换位思考、包容承载、正桃花、婚姻、财、业绩
- **适用**：成年人看业绩财运；孩子看学习成绩；天医结尾家庭财婚象意明显
- **禁忌**：
  - 天医不宜过多 → 选择多、婚姻关系复杂
  - **天医+五鬼** → 婚变、婚外情、地下情 ⚠️
  - **天医+祸害** → 夫妻口舌不断、不同频 ⚠️

### 🔄 伏位星（同星延续）
- **关键词**：跟前不跟后、延续、聚集、慢半拍、赖家
- 本身不单独定性，主要看跟随谁、延续谁
- 5和0也被纳入伏位/桥梁的特殊规则

### 💪 绝命星（阴金）
- **关键词**：行动力强、敢拼敢干、亲力亲为、豪爽仗义、讲义气但易冲动
- **适用**：冲锋、执行、拼搏、投资、开拓；要有吉星制约
- **车牌第一凶**：易速度快、抢黄灯、跟车近、较劲
- 绝命人「闲不住」，外面的事比家里事重要

### 🧠 五鬼星（火，主礼）
- **关键词**：脑力、变通、学习能力、接受新鲜事物、理性、城府、机会多
- **适用**：脑力工作、财务、工程、策划、需要变通和学习的岗位
- **五鬼走脑不走心**，擅长判断「应不应该」而非「高不高兴」
- **车牌第二凶**：偏意外、不可控
- **五鬼结尾风险重**：破财收不住、意外、血光、牢狱、睡眠差

### 🗣️ 祸害星（土，偏阴土）
- **关键词**：逻辑清晰、表达准确、口才、沟通、固执、脾气只发不收
- **适用**：律师、讲师、厨师、外科等以口为业或高压专业场景
- **祸害结尾称「一场空」**：财空、人空、人财两空；致病性、手术、小人官非

### 💧 六煞星（水，主智）
- **关键词**：亲和力、服务意识、公关能力、形象气质、心思细腻、要求完美
- **适用**：服务、客服、酒店、餐饮、讲师等需要耐心和亲和的行业
- **五鬼+六煞相邻**：女性易胡思乱想、情绪低落；男性偏桃花旺

## 五、手机号码拆分规则与0、5特殊规则

### 基本拆分规则
1. 从左至右拆分，相邻两个数字形成一个星位
2. 第一个和最后一个数字通常只拆一次
3. 中间数字在有条件时可前后各拆一次
4. **重复数字必须一起看**（如6888：68+88伏位）
5. **伏位跟前不跟后**
6. 5和0有伏位属性，又有桥梁属性，必须结合前后判断

### 0的规则（手机号禁忌）
- **手机号码不允许出现0**（车牌/门牌/银行卡中间可有0）
- 中间一个0：多看病灶或问题点
- 后面跟0：多看手术、拆毁、毁坏信息
- 多个0：体质弱、底子差、抵抗力弱
- 车牌/门牌/银行卡：结尾不宜为0

### 5的规则（承接与升能量）
- 5是桥梁，承接、连接、升能量
- 40分→60分→80分→100分，逐级提升
- 本来100分，经5放大可达200分以上大磁场
- **「包饺子」**：两头同类数字、中间夹一个（如727、13313），放大能量
- 原则：不要追大，先看能否拿得动、是否平衡

### 能量大小与「拿不动」
- 100分以内不算大磁场
- 200分以上普通人多不建议使用
- 比喻：「一麻袋一百万能拎走，一麻袋一个亿拎不动」
- 号码匹配重「**整体平衡**」

## 六、东西四命：计算方法与选号核心

### 为什么重要
- 每颗星四组数字，一个人通常只能用其中**两组**
- **1349为一组（东四命），2687为一组（西四命）**
- 组内互配多形成吉星，跨组多形成凶星
- 号码结尾必须符合自己的东西四命

### 时间口径（以立春为界）
- 立春之前出生 → 按上一年计算
- 立春当天出生 → 看具体时刻，时刻之前按上一年，之后按当年

### 计算步骤
1. 确定出生年份（立春修正后）
2. 年份四位数字相加，持续加到个位（例：1978→1+9+7+8=25→2+5=**7**）
3. **女性**：个位数 + 4，超过9继续相加到个位
4. **男性**：11 - 个位数，两位数继续相加到个位
5. 若最终得数为5：男入坤宫按**2**看；女入艮宫按**8**看
6. 根据最终数字归入1349组或2687组

### 组选原则
- 1349组内：13/31=天医，14/41=生气，19/91=延年，34/43=延年，49/94=天医，39/93=生气
- 2687组内：68/86=天医，26/62=延年，27/72=天医，78/87=延年，28/82=生气，67/76=生气
- 跨组组合 → 绝命、五鬼、六煞、祸害

## 七、车牌、门牌、银行卡应用口径

### 载体区别
| 载体 | 对象 | 核心关注 |
|------|------|----------|
| 手机号码 | 针对人 | 最严格，不建议有0 |
| 门牌号 | 家庭/办公室空间 | 代表空间氛围 |
| 车牌号 | 车辆移动空间 | 重点看安全，结尾尤重要 |
| 银行卡号 | 财库 | 储蓄卡宜延年结尾 |

### 银行卡号
- **储蓄卡延年结尾为佳**（财不好出来，利于积累）
- 女性大延年在银行卡上可放宽（不是人格号码）
- 信用卡不按此口径

### 门牌号象意
| 门牌星位 | 空间象意 |
|----------|----------|
| 生气门牌 | 其乐融融，有矛盾也容易过去 |
| 延年门牌 | 家人对家有责任感、承担感 |
| 天医门牌 | 爱的氛围浓，互相关心 |
| 伏位门牌 | 家人赖家，进屋后谁都不想动 |
| 绝命门牌 | 家人不着家，行动多、在外多 |
| 五鬼门牌 | 各过各的，互不干扰 |
| 祸害门牌 | 容易口舌、互相挑剔 |
| 六煞门牌 | 较整洁，重细节、重形象 |

- 门牌不好：不要改掉原门牌，可在原门牌后**补贴一个数字**化解
- 补数思路：生气压五鬼、天医化绝命、延年承六煞、伏位缓祸害

### 车牌号
- 英文字母转换：A=1, B=2, C=3, D=4, E=5, F=6, G=7, H=8, I=9（循环）
- **重点看最后两位**
- 中间可有0，结尾不宜为0；结尾为5按0的空性看
- **第一凶：绝命车牌**（速度快、抢灯、较劲）
- **第二凶：五鬼车牌**（意外、不可控）

## 九、号码分析六步法

| 步骤 | 内容 | 说明 |
|------|------|------|
| **第一步** | 看结尾 | 结尾约占70%信息，是最终结果 |
| **第二步** | 看星位能量分值 | 找出号码中分值最高、最突出的能量场 |
| **第三步** | 看5和0 | 5看承接与升能量；0看问题点、病灶 |
| **第四步** | 看星位搭配 | 按「前因后果、顺位作用、隔位不作用」讲故事 |
| **第五步** | 看五行属性 | 磁场太单一或五行偏枯时参考 |
| **第六步** | 看命卦/东西四命 | 号码好不等于本人能用，结尾必须符合 |

### 实操选号提醒
- 先排除禁忌：手机号含0、结尾凶星过重、天医过多、天医接五鬼、天医接祸害、女性大延年
- 再看行业、年龄、性别、目标
- 最后看东西四命与八字喜用神
